# E-Commerce Web Application (Customer Journey & Market Optimization)

A full-stack MERN e-commerce web application focused on improving customer journey, conversion and market optimization.

## Features
- User Authentication (Login/Register)
- Product Listing & Search
- Cart & Checkout Flow
- Order Management
- Admin Dashboard
- Responsive UI

## Tech Stack
- Frontend: React.js, Context API, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Tools: Postman, Git, GitHub
